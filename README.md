# 📚 citation-formatter
 
一个用于 [Claude.ai](https://claude.ai) 的自定义 Skill，帮你把乱糟糟的文献信息自动整理成符合**任意指定规范**的参考文献列表。
 
无论是毕业论文、期刊投稿还是课程作业，只要把你的格式要求告诉它，剩下的交给 AI 来做。
 
---
 
## 🎯 解决什么问题
 
每个学校的毕业论文、每本期刊的投稿要求，参考文献格式几乎都不一样。手动对照格式说明一条条核对，费时又容易出错。
 
这个 Skill 让你只需做一件事：把格式规范粘贴给它，然后把文献信息扔给它，格式化好的列表就出来了。
 
---
 
## ✨ 主要功能
 
- **自定义规范优先**：不绑定任何固定格式，完全按照你提供的模板和示例来，字段顺序、标点、括号一个不差
- **自动识别文献类型**：专著、期刊论文、学位论文、会议论文、网络资源、报纸、标准/法规、编著章节……不需要你手动标注类型
- **智能追问**：遇到特征不明确的文献，只问一个简短的问题（"这是专著吗？"），不会一口气抛出一堆选项
- **缺失字段提示**：如果原始文献信息不完整，用 `[?]` 占位并告知哪里需要补，**不会捏造信息**
- **持续累积**：可以分批发文献，它会接着编号，最后一次性输出完整列表
- **支持中英文混排**：中英文文献混合处理，标点符号按规范自动适配

## 🚀 使用方法
 
### 第一步：安装 Skill
 
1. 下载本仓库中的 `citation-formatter.skill` 文件
2. 打开 [Claude.ai](https://claude.ai)，进入 **Settings → Skills**
3. 点击 **Install Skill**，上传 `.skill` 文件
### 第二步：告诉它你的格式规范
 
新建对话后，把你的格式要求发给 Claude，包括各文献类型的格式模板和正确示例。例如：
 
```
我的参考文献格式要求如下：
 
专著：[序号] 作者.书名[M].出版地:出版社,年份.
示例：[1] 王力.汉语语法[M].北京:商务印书馆,1985.
 
期刊论文：[序号] 作者.文章名[J].期刊名,年份,卷(期):起止页码.
示例：[2] 张三,李四.语言习得研究[J].现代语言学,2020,8(2):45-60.
 
学位论文：[序号] 作者.论文题目[D].城市:学校,年份.
示例：[3] 王五.二语写作中的语块使用研究[D].上海:复旦大学,2019.
```
 
它会确认识别到的类型，然后进入待命状态。
 
### 第三步：粘贴文献，直接输出
 
把你收集到的文献信息（不管什么格式）发给它：
 
```
Carolyn Merchant. The Death of Nature: Women, Ecology, and the Scientific Revolution. HarperCollins, 1980.
 
Patricia Yaeger. Dirt and Desire: Reconstructing Southern Women's Writing, 1930-1990. University of Chicago Press, 2000.
 
李银河. 女性主义[M]. 济南:山东人民出版社,2005.
```
 
输出示例：
 
```
[1] Carolyn Merchant.The Death of Nature: Women, Ecology, and the Scientific Revolution[M].[?]:HarperCollins,1980.
[2] Patricia Yaeger.Dirt and Desire: Reconstructing Southern Women's Writing, 1930-1990[M].Chicago:University of Chicago Press,2000.
[3] 李银河.女性主义[M].济南:山东人民出版社,2005.
 
⚠️ 需补充信息：
- [1] 缺少出版地
```

## 💡 使用技巧
 
**换规范**：说"格式要求变了"，它会清除旧规范，重新加载。适合同时写多篇投稿不同期刊的论文。
 
**批量处理**：可以一次性粘贴几十条文献，它会逐条处理，无法判断类型的统一在最后提问。
 
**没有自定义规范**：如果只说"帮我格式化参考文献"而没提供规范，它会询问你是否使用通用规范（GB/T 7714-2015、APA 7th、MLA 9th 等）。
 
**核查格式**：如果你觉得某条格式不对，让它"逐字段对比解释"，它会展示用的模板和原始信息，帮你确认是规范理解有误还是原始数据缺失。

## 📋 支持的文献类型
 
| 类型 | 识别依据 |
|------|----------|
| 专著（书籍） | 有出版社、出版地，无期刊名 |
| 期刊论文 | 有期刊名、卷/期号、页码 |
| 学位论文 | 含"硕士"/"博士"/"thesis"/"dissertation" |
| 会议论文 | 含会议名称、"proceedings"/"论文集" |
| 网络资源 | 有 URL/DOI 且无传统出版信息 |
| 报纸文章 | 有报纸名称、版次 |
| 标准/法规 | 含标准编号（如 GB/T）或法规名称 |
| 编著章节 | 含"见："/"In:" 及主编姓名 |
